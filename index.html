PROJECT NOTE // 01

“BOBOT” — A Digital Solution for Streamlining HM Equipment Borrowing

BOBOT is designed to improve resource management in the Hospitality Management (HM) Department by streamlining equipment borrowing. The system aims to make the process more organized and convenient by helping track equipment, manage records, and reduce manual paperwork.

PROJECT NOTE // 02

Maze Runner Robot

An automated robot designed to navigate a maze and find its destination. Using sensors and programmed algorithms, it detects walls, avoids obstacles, and determines a path to the goal. The project demonstrates robotics, programming, electronics, and problem-solving in an autonomous system.
